Tải lên nội dung

Thêm bài mô phỏng hoặc câu lệnh mới mà không cần chạy lại mã. Nội dung thêm hiện ngay trên máy này; muốn học sinh và đồng nghiệp cùng thấy, làm theo mục 4.

1. Thêm thí nghiệm mô phỏng

Chọn file HTML do AI tạo (Claude, AI Studio…). Tối đa khoảng 3 MB.

2. Thêm câu lệnh mẫu

Câu lệnh hiện ở mục "Thư viện câu lệnh của thầy cô" trong trang Trợ lí AI.

3. Nội dung đã thêm

Đang tải…

4. Đưa lên web cho mọi người

  1. Bấm Tạo gói cập nhật: máy tải về file noi-dung.json và các file bài, ảnh bìa mới.
  2. Vào kho GitHub của web, chọn Add file → Upload files.
  3. Kéo tất cả file vừa tải vào (file noi-dung.json cũ sẽ được thay), rồi bấm Commit changes.
  4. Đợi khoảng 1–2 phút, tải lại web: nội dung mới hiện cho mọi người, không phải chạy lại mã.
Chưa đưa lên GitHub thì nội dung chỉ nằm trong trình duyệt của máy này. Xóa dữ liệu trình duyệt sẽ mất, nên hãy tạo gói cập nhật để giữ bản sao.
